# 小耳朵英语 Little Ears

给零基础一年级孩子的家庭英语网站：**以看动画为主，每天 15 分钟，多听、多说**。
不重复机构课程，按孩子的生活场景编排；不打分，只让孩子看到自己学到哪里了。孩子不识字也能用：图片 + 声音 + 大按钮。

- 搭建思路（目标、每日路线、功能结构、视频片单、跟我说课程、技术方案）：[`docs/plan.md`](docs/plan.md)
- **部署到华为学习平板**（一步步操作）：[`docs/deploy-huawei.md`](docs/deploy-huawei.md)
- **部署到国内云服务器**（阿里云 / 腾讯云、Nginx、ICP 备案）：[`docs/DEPLOY_CN.md`](docs/DEPLOY_CN.md)
- 可运行原型：本仓库根目录的 `index.html`（纯静态，无需安装任何依赖）

## 四个分栏

| 分栏 | 内容 |
|---|---|
| **今天** | 每日 3 步路线：看动画 → 跟我说 → 磨耳朵，每步写着「接下来」是什么；「我学到哪里了」显示每个动画系列看到第几集、跟我说学到第几课、磨耳朵过了几关；完成一天得一张贴纸 |
| **看动画** | 接着看、我的动画、选集（看完打勾）、播放页（看完了 / 只听不看）；给家长的推荐片单（分入门、进阶、提高三个阶段，每个阶段 4 个主推 + 2 个备选） |
| **跟我说** | 16 课日常口语，每课 3–4 句；问答（先听问题再回答）或跟读；点读、录音回放；不打分，说完就鼓励 |
| **磨耳朵** | 听音选图（一关一个主题，逐关前进）、动起来（听指令做动作）、循环听句子、只听动画 |
| 家长中心 | 学习报告、视频管理（粘贴 B 站链接）、学习设置、设备检查；右上角锁形图标进入，需答一道乘法题 |

## 怎么打开

**多个孩子共用一台设备：** 一个家庭可保留 1–3 个孩子档案。点顶部头像或名字切换，在弹窗中添加孩子，点「编辑」改英文名、选颜色或删除档案；删除前会再次确认，最后一个档案不能删除。每个孩子的学习记录、视频链接和设置独立。已有的单孩子数据会自动成为第一个档案，无需重新填写。

「家长中心 → 学习设置 → 备份与恢复」支持复制或下载全家备份、选择 JSON 文件恢复，也支持旧版单孩子备份。恢复会替换本机全部档案。档案只存在当前浏览器，没有账号或后台。实现与可重复测试见 [`docs/multi-child-profiles.md`](docs/multi-child-profiles.md)。

**电脑上试用：** 在仓库目录运行下面的命令，然后用 Chrome / Edge 打开 <http://localhost:8000>

```bash
python3 -m http.server 8000
```

**给孩子在平板 / 手机上用：** 部署成 https 网站，用平板浏览器打开一次并刷新，再「添加到桌面」。

- 华为学习平板的完整步骤（含学习模式管控、话筒权限、发音检查）：[`docs/deploy-huawei.md`](docs/deploy-huawei.md)
- 放到阿里云或腾讯云轻量服务器、做 ICP 备案、用脚本或 GitHub Actions 发布：[`docs/DEPLOY_CN.md`](docs/DEPLOY_CN.md)
- 网站本身会缓存到设备上（Service Worker），网络慢时也能秒开；动画在 B 站播放器里播放，仍然需要联网。
- 字体、样式和脚本都在本仓库里，页面不请求 Google Fonts、jsDelivr、unpkg、cdnjs 或统计脚本。
- 浏览器只在 `https://` 或 `http://localhost` 下允许使用话筒和离线缓存，所以正式使用一定要配 HTTPS。

**第一次在新设备上用：** 进「家长中心」：
1. 「视频管理」里给推荐片单中的 1–2 个系列粘贴 B 站链接
2. 点顶部头像创建孩子档案，在「学习设置」里填当前孩子的年龄
3. 「设备检查」里试听英语发音、测试录音

## 浏览器支持

| 功能 | 华为平板（华为浏览器） | iPad / iPhone Safari | 电脑 Chrome / Edge |
|---|---|---|---|
| 播放动画（B 站外链 / mp4） | ✅ | ✅ | ✅ |
| 英语朗读 | ⚠️ 取决于系统语音引擎，用「设备检查」试听确认 | ✅ 系统自带发音人（推荐 Daniel 英音） | ✅ |
| 跟读录音 + 回放 | ✅（需允许麦克风） | ✅ | ✅ |
| 离线打开 / 添加到桌面 | ✅ | ✅ | ✅ |

学习进度和视频链接保存在当前浏览器里（`localStorage`），换设备、换网址时用「家长中心 → 学习设置 → 备份与恢复」搬过去；清除浏览器数据会丢失。云同步放在正式版。

## 目录结构

```text
index.html            页面骨架
manifest.webmanifest  添加到桌面用的应用信息（名称、图标）
sw.js                 离线缓存
assets/css/style.css  样式（浅色 / 深色两套配色）
assets/fonts/         本地字体（SIL OFL 1.1 授权，见 OFL-*.txt）
assets/icons/         桌面图标
assets/js/data.js     内容：推荐片单、跟我说 16 课、听音选图词库、动作指令
assets/js/store.js    学习进度（看到第几集、学到第几课、过了几关）
assets/js/speech.js   朗读和录音
assets/js/app.js      页面路由和各个学习活动
docs/plan.md          网站搭建方案
docs/deploy-huawei.md 部署到华为学习平板
docs/DEPLOY_CN.md     部署到国内云服务器（备案、Nginx、自动发布）
deploy/               Nginx 配置和 SSH/rsync 部署脚本
.github/workflows/    用仓库 Secrets 发布到服务器的 GitHub Actions
```

> 改动文件后：`sw.js` 会在后台自动取新版本；如果新增或删除了文件，记得同步修改 `sw.js` 里的 `SHELL` 列表并把 `VERSION` 加一。

## 更新学习内容

内容都在 `assets/js/data.js`：

- **加一个推荐动画系列**：在 `series` 里照着已有的写一条，`stage` 填 1 / 2 / 3（入门 / 进阶 / 提高），`q` 是在 B 站搜索用的关键词。视频链接本身由家长在「家长中心 → 视频管理」里添加，不写在代码里。
- **加一课「跟我说」**：在 `lessons` 末尾加一课，每句 `{ pic: '图片', q: '问题（可选）', a: '要说的句子', zh: '中文意思' }`；`{name}`、`{age}` 会换成孩子的名字和年龄。
- **加听音选图的词**：在 `themes` 对应主题的 `words` 里加 `{ en: 'rubber', pic: '🧽' }`。

孩子的进度按课程 id、系列 id 记录，**加内容不会影响已有进度**；不要修改已有课程或系列的 `id`。
