# 部署到华为学习平板

思路：把网站放到一个 **https 网址** 上（先用免费的 GitHub Pages 试用，正式使用放到自己的服务器），平板上用 **华为浏览器** 打开一次，网站会自动存到平板上（离线缓存）；再 **添加到桌面**，孩子以后点图标就能用，网络慢或断网也能打开。

这个方式不需要在平板上装任何 App。鸿蒙 4 及以前的版本，和鸿蒙 5（HarmonyOS NEXT）都适用。

> 为什么不直接把文件拷到平板里打开？因为浏览器只在 `https://` 网址下允许使用话筒和离线缓存，而且平板的文件管理器打开本地网页时常常加载不全。

---

## 第一步：开通网址（一次性，在电脑或手机上操作）

1. 用浏览器打开仓库的 Pages 设置页：<https://github.com/Chaos-yi/Young-Learners-English/settings/pages>（需要登录你的 GitHub 账号）
2. 在 **Build and deployment** 里：
   - **Source** 选 `Deploy from a branch`
   - **Branch** 选 `claude/epic-gates-w5p8og`，右边文件夹选 `/ (root)`，点 **Save**
3. 等 1–3 分钟后刷新这个页面，顶部会出现 *Your site is live at …*。网址是：

   **<https://chaos-yi.github.io/Young-Learners-English/>**

4. 先在电脑上打开这个网址，确认首页能正常显示。

> 网址后半段 `Young-Learners-English` **区分大小写**，必须和上面一模一样，否则会显示 404。

### 放到自己的服务器（正式使用）

网站是纯静态文件，把整个仓库目录上传到服务器的网站目录即可，不需要数据库和后台程序。有三点要注意：

1. **必须开启 HTTPS**（云厂商一般提供免费证书）。没有 HTTPS，话筒录音和离线缓存都用不了。
2. **`sw.js` 不要缓存**，否则平板可能很久拿不到新内容。
3. 确认 `.webmanifest` 和 `.woff2` 文件返回正确的类型。

可直接使用仓库里的 Nginx 配置和部署脚本。购买服务器、域名、ICP 备案、HTTPS 证书、DNS，以及用 SSH/rsync 或 GitHub Actions 发布，按 [`DEPLOY_CN.md`](DEPLOY_CN.md) 操作。配置文件在 `deploy/nginx/`，发布脚本是 `deploy/deploy.sh`。

国内服务器绑定域名需要先完成 ICP 备案。

## 第二步：在平板上打开

1. 平板连上家里的 Wi-Fi。
2. 打开平板自带的 **华为浏览器**。如果学习模式下找不到浏览器，先看第五步。
3. 在地址栏输入 `chaos-yi.github.io/Young-Learners-English/`，打开。
4. 等首页完全显示后，**再刷新一次**。这一步会把整个网站存到平板上，之后断网也能打开。

---

## 第三步：家长做一次设备检查（约 3 分钟）

点右上角的 **锁形图标** → 答一道乘法题 → 进入 **家长中心** → **设备检查**。

| 检查项 | 怎么做 | 正常的样子 | 不正常怎么办 |
|---|---|---|---|
| 英语发音 | 点「试听」 | 听到清楚的英语：*Hello! I'm your English friend. Apple, banana, orange.* | 见下方「发音问题」 |
| 话筒 | 点「测试录音」，对着平板说一句话 | 弹出「允许使用麦克风」时点允许，3 秒后能听到自己的声音 | 见下方「话筒问题」 |
| 播放动画 | 先在「视频管理」添加一个系列，再到「看动画」试播 | 能正常播放、有声音 | 换一个 B 站视频试试（个别视频不允许在其他网站播放） |
| 离线使用 | 看状态 | 绿色勾 ✓ | 刷新一次页面再看 |
| 保存学习进度 | 看状态 | 绿色勾 ✓ | 不要用无痕模式 |

然后：
- **视频管理**：从推荐片单里挑 1–2 个系列（零基础建议从「入门」阶段开始），点「在 B 站搜索」找到完整的合集，把链接粘贴进来，填总集数，保存。
  - 已经在手机或电脑上填好了？不用重新填：在原来的设备上进 **家长中心 → 学习设置 → 备份与恢复 → 复制备份**，用微信「文件传输助手」发到平板；在平板上进同一个位置，把内容粘贴进去，点两次「恢复」。
- **学习设置**：填孩子的英文名和年龄（会出现在 *My name is …* 这类句子里）；语速先用 0.8 左右；如果有多个英语发音人，逐个试听，选最清楚的那个。

---

## 第四步：添加到桌面

在华为浏览器里打开网站首页，点浏览器的 **菜单**（一般在屏幕底部或右上角，图标是「≡」或「⋮」），找到 **「添加到桌面」**（有的版本叫「添加快捷方式」或「安装应用」）。

桌面上会出现一个黄色的 **小耳朵** 图标。以后孩子点这个图标就能进入，界面是全屏的，没有浏览器地址栏，不容易误点到别的网站。

---

## 第五步：学习平板的管控设置

学习平板一般有「学习模式 / 儿童模式」或家长管控功能（比如系统设置里的「健康使用平板」，或者手机上的「华为家长助手」App）。默认可能不允许孩子打开浏览器或陌生网站。不同型号的菜单名字略有不同，大致需要：

1. **应用管控**：允许 **华为浏览器**。桌面上的小耳朵图标依赖浏览器运行。
2. **上网管理 / 网址白名单**（如果有）：添加 `chaos-yi.github.io`。
3. **使用时长**：可以设每天 20–30 分钟，和网站自带的「15 分钟到啦，休息一下眼睛」提醒配合。

如果学习模式有网址白名单，动画播放还需要允许 `player.bilibili.com`（B 站播放器）。「看动画 → 推荐片单」里的「在 B 站搜索」链接是给家长找视频用的，孩子模式下打不开也没关系。

---

## 日常使用

- **每天**：点小耳朵图标 → 「开始今天的学习」，按 3 步走完（看动画 → 跟我说 → 磨耳朵），大约 15 分钟。
- **进度和视频链接** 保存在这台平板的浏览器里：不要在浏览器设置里「清除数据 / 缓存」，也不要换浏览器使用，否则会丢。
- **内容更新**：仓库里的内容改了以后，平板联网时打开两次就会更新。第一次在后台下载新版本，第二次打开就是新版本。

---

## 以后换到自己的服务器

学习进度和视频链接是跟着网址保存的，换了网址（比如从 `github.io` 换到自己的域名）新网址里是空的。搬家方法和上面一样：

1. 在平板上打开旧网址 → 家长中心 → 学习设置 → 备份与恢复 → **复制备份**
2. 打开新网址 → 同一个位置粘贴 → 点两次「恢复」
3. 重新「添加到桌面」，删掉旧的桌面图标

## 常见问题

**打不开，或者一直在转圈**
`github.io` 在国内部分网络下比较慢。尽量用家里 Wi-Fi，过一会儿再试；只要成功打开过一次并刷新过，以后就从平板本地打开，不再受网速影响。如果长期打不开，改放到国内服务器。一步步的购买、备案和发布说明在 [`DEPLOY_CN.md`](DEPLOY_CN.md)。

**显示 404**
检查网址大小写，以及第一步的 Pages 设置是否已保存、是否显示了 *Your site is live*。

**发音问题：没声音、或者用中文口音读英文**
1. 先确认平板音量已打开、不在静音状态。
2. 家长中心 → 设备检查 → 英语发音：如果提示「没有找到英语发音人」，到平板 **设置 → 辅助功能** 里找 **「文字转语音输出」**，看看能否选择或下载英语语音。
3. 家长中心 → 学习设置 → 发音人：有多个时逐个试听，选最清楚的。

「跟我说」和「磨耳朵」的朗读用的是平板系统自带的语音引擎，不同设备效果差别很大（动画的声音不受影响）。如果以上都不理想，下一步可以把所有句子和单词换成**提前录好的标准英音音频**，打包进网站，离线也能播放，就不再依赖平板的语音引擎了（见 [搭建方案](plan.md) 的 v1 计划）。

**话筒没反应 / 不能录音**
- 第一次录音时浏览器会问「是否允许使用麦克风」，要点允许。点过拒绝的话，到浏览器的网站设置里改回允许。
- 还不行就到平板 **设置 → 应用和服务 → 权限管理**（或类似菜单），允许华为浏览器使用麦克风。
- 实在不能录音也不影响学习：跟读时孩子大声说出来，点话筒就算说完了。

**动画播放不了**
- 先确认联网。动画是在 B 站播放器里播放的，不能离线。
- 个别 B 站视频不允许在其他网站播放，换一个上传者的版本试试。
- 学习模式有网址白名单的话，需要允许 `player.bilibili.com`。

**学习进度或视频不见了**
通常是清除了浏览器数据，或者用了无痕模式、换了浏览器。进度和视频链接只保存在这台平板的这个浏览器里。
